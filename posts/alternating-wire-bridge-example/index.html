Alternating Wire Bridge: One Elegant Code, an Entire Structure

August 19, 2021 Andres Silva

Some of the most visually complex structures emerge from some of the simplest rules. This alternating wire bridge demonstrates that principle with unusual clarity: a single, clean piece of code generates the entire structure — and the spatial effect it produces is extraordinary.

What Changed from the Earlier Design

This bridge evolved directly from an earlier footbridge concept through two specific refinements:

The deck was straightened. The curved deck in the original design introduced construction complexity and visual ambiguity. A straight deck creates a clear horizontal datum that makes the cable system’s rotation all the more dramatic by contrast.

The cable layout was reorganized. Cables now alternate left to right and rear to front, rather than running in parallel. This alternation creates patterns in the air that look, from the front, like a continuous rotation. The structure appears to twist as you walk toward it — an impression that changes depending on where you stand.

What the Rotation Effect Actually Does

The planes that trace along the top arch rotate at a concurrent angle, creating a slow, continuous shape-changing quality across the full length of the bridge. What appears from one angle as a conventional arch system reveals itself from another angle as a rotating, dynamic structural entity.

This feature draws you in. It invites observation from multiple vantage points — which is perhaps the highest compliment a public structure can receive. Good public infrastructure is used; great public infrastructure is also experienced.

Code as Elegance

The code that generates this structure is, in a word, elegant. A single, well-organized script gives birth to the entire bridge — deck, cables, arch, spacers, all of it. Each code area has a clear, distinct purpose; the organization of the code reflects the organization of the structure.

The rotation of the main beam as it sweeps over the lower bridging deck is visible both in the Dynamo graph and in the rendered geometry — a correspondence between code architecture and physical architecture that represents the ideal state of parametric design.
