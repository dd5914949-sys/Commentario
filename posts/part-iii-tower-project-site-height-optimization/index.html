Part III: Tower Project — Site & Height Optimization with Generative Design

July 4, 2021 Andres Silva

Following on from Part II’s massing study, Part III confronts the critical urban question: where exactly on the site should this tower be placed, and how should its height respond to the surrounding context?

The answer shouldn’t come from intuition alone. It should come from data — generated by a parametric solver that can test every possible position simultaneously.

The Method: View Ray Analysis

The generative design code for this study was streamlined from the full Part II approach, using a simplified building footprint to represent the tower at the site scale. The objective: move the building around the perimeter of the site, finding the position that achieves the best unobstructed views.

By radiating lines in every direction from each tested position, any obstacles within the view range are identified. Each obstruction receives a penalty based on two factors: distance (closer obstructions penalize more heavily) and height (taller obstructions block more sky and penalize accordingly). The solver accumulates these penalties across all view directions and all tested positions, then identifies the minimum-penalty location.

What the Solver Found

The study’s recommendation: position the tower as close as possible to the adjacent park along the property boundary, while maintaining maximum distance from the L-shaped neighboring building.

The output visualization makes this clear: the red rectangle marks the property line; the blue geometry shows the solver’s suggested optimal positions; the grey building represents the neighboring structure whose presence creates the dominant view obstruction.

A filter in Column 3 (V) of the output isolates the selected space, demonstrating the elevated Built-Up Area ratio that the recommended position achieves.

Validation Through Comparison

The most satisfying outcome of this study: a side-by-side comparison between the generatively optimized placement and the original intuitive design concept reveals near-perfect alignment. The footprints and features match.

This is what generative design should do — not replace design judgment, but validate it. When algorithmic optimization confirms that the designer’s instinct was correct, the decision to proceed with the original concept carries far more confidence than intuition alone could provide.
